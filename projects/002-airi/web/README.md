# AIRI 独立研究网页

纯静态 HTML / CSS / JavaScript，无安装依赖和构建步骤。所有网页源码与资源在本目录。

## 本地运行

在此目录运行：

```powershell
python -m http.server 2526 --bind 127.0.0.1
```

在浏览器打开 `http://127.0.0.1:2526/`。此地址仅在本机服务启动时有效；按 Ctrl+C 停止。也可以直接打开 `index.html`，但建议通过本地静态服务器检查。

## 阅读顺序

引导总览图 → 当前投入判断 → 六点摘要（能力、本质、技术沉淀、场景、扩展方向、个人意义）→ 交互式能力与源码对照。现阶段归档参考，暂不继续深入研究。

## 交互

- 能力地图：9 个选项切换机制、启用条件、限制和资料出处。键盘支持方向键、Home 与 End；Tab 可进入详情及资料链接。
- 交互链路：4 个场景，每个 5 个步骤，逐步查看解释与来源。
- 控制机制：对照角色指令、浏览器桥接、系统输入与游戏接口；包含未执行的 Minecraft 工具参数示意。
- 页内导航、固定源码链接、外部官方体验入口。
- 窄屏布局、可见键盘焦点、减少动态效果偏好。

所有数据均为固定研究说明。无第三方请求、模型调用、设备权限访问或保存个人信息。外部链接由访问者点击后打开。

## 静态发布

仓库 `.github/workflows/deploy-pages.yml` 把本目录复制到 `_site/002-airi/`。

已部署子路径：`/0928_codex_project/002-airi/`。页面的 CSS、JavaScript、图片均使用相对路径，支持子目录托管。本站没有客户端路由，页面内部使用锚点导航。

[在线研究网页](https://yydshly.github.io/0928_codex_project/002-airi/) 已于 2026-09-28 发布并核验；摘要、图片和交互正常。原项目入口为 [AIRI 官方体验](https://airi.moeru.ai/)，它与本仓库展示页面不同。

## 文件

- `index.html`：中文研究页面、结构与静态内容。
- `styles.css`：响应式布局、颜色、排版和交互状态。
- `app.js`：能力切换、链路说明与固定提交的来源链接。
- `assets/airi-capability-overview.png`：用户选定的引导图，内置 imagegen 生成；原文件与提示词保存在项目 `assets/`。
- `assets/airi-map.svg`：自制技术结构示意；不含第三方角色素材。
- `QA.md`：本研究网页的实际验证记录。
