# 008 · AI Money Maker Handbook：AI 创业思路与案例

[AI Money Maker Handbook](https://github.com/XiaomingX/ai-money-maker-handbook) 的本质是**面向 AI 创业的思路整理与案例收集库**。它汇集方向、方案推演、模拟案例、资源和创业问答，帮助探索 AI 创业方向，发现需求、构思产品并分析商业模式。

- **能力是什么：**用不同场景提供启发；我们将商业思考整理为痛点、人群、最小产品、获客、收费、留存六个要素。
- **内容有哪些：**图片、文案、音频、直播、绘本、视频、工具自动化、知识数据咨询。固定版本整理了 444 篇副业章节、70 篇创业问答，首页另列 31 条创业文章外链。
- **为什么值得整理：**可以作为自己的 AI 产品化探索入口，持续积累想法、需求观察、样例与反馈；先成为个人思路工作台，再按真实使用需求考虑对外产品化。

## 网页已有能力

1. **我的起点**：记录已确认的后端开发、近期使用 AI、希望尝试首笔收入、从公开渠道寻找人群四项条件。
2. **看懂这个库**：七类能力归纳、内容结构图、思路拆解与组合。
3. **思路资料库**：514 篇固定版本原文入口，支持关键词、系列、主题、重点抽读筛选、分页与收藏。
4. **我的小试验**：整理能力、人群、问题、交付、需求原话、验收条件、下一步、成本和实际进展。
5. **研究与来源**：原库版本、许可、方法、证据范围和当前个人价值。
6. **继续对话**：导出 Markdown 或复制探索记录，把真实观察带回当前对话继续梳理。

交互由浏览器本地完成，没有接入在线大模型。个人草稿与收藏只保存在当前浏览器，不随网站发布，不跨设备同步。浏览器禁用存储时仍可编辑和导出。

## 对当前用户的价值

用户确认自己是后端程序员，近期主要使用 AI，希望尽快尝试第一笔收入，目前没有明确人群，希望从公开渠道寻找。

当前建议把思路收集用于寻找可观察的需求入口，先看表格整理与报表、API 对接与小流程自动化、AI 工具配置与任务落地三个方向。它们是基于已知条件提出的假设，尚无客户需求或成交验证。时间、预算、行业经验和销售偏好仍待补充。

当前讨论进一步拓展到图片、文案、音频、直播、绘本等内容方向，以及把思路库本身做成持续迭代的产品。三个初始服务方向只是入口，完整方向图与产品化设想见 understanding.md。
