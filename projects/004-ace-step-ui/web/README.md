# ACE-Step UI 独立研究展示页

本目录是纯静态 HTML、CSS、JavaScript，源码均在项目目录内，无需安装依赖；浏览器展示不依赖 ACE-Step 服务。页面包含能力切换、创作路径、系统架构、请求追踪、模型原理、重绘掩码和实现取舍，不执行音乐生成或音频上传。首页新增三个官方音频播放器和原作者界面动图，读取远程媒体需要联网。

## 本地查看

新增 [overview.html](overview.html) 完整总览页：集中展示一张可放大的总览图，并链接完整研究说明；图有 PNG 与 SVG 两种格式。无需联网、无模型请求。可从首页和创作指南进入。

直接打开 `index.html` 即可。若使用本地静态服务器，可在项目目录 `projects/004-ace-step-ui/` 运行：

```powershell
python -m http.server 2530 --bind 127.0.0.1
```

然后访问 `http://127.0.0.1:2530/web/`。这样页内的研究记录链接也可打开。服务器运行是可选的；项目本身无安装或构建步骤。

## 交互与来源

- 新增 [creation.html](creation.html) 创作控制指南，使用本目录的 creation.css / creation.js 和共享 styles.css，无外部依赖与媒体请求。四个创作起点支持点击及键盘切换；六类入口分别说明操作、控制、试听与迭代，另列产品建议。

- 六个能力选项切换说明与固定提交的源码链接；支持方向键、Home、End 和 Tab。
- 三条创作路径是基于原项目功能整理的使用示意，不是已完成的本机创作结果。
- 六步请求追踪支持点击、方向键、Home、End；与能力选项独立切换。每步说明实际接口、函数、状态或存储行为。
- 模型部分含可展开原理解读和可拖动重绘范围。范围始终满足开始早于结束；换算按 12 秒、25 Hz、300 帧的数学示例展示，不加载音频或调用模型。
- 系统图与模型机制均链接固定提交源码。UI 与模型提交分别研究，尚未验证配套运行；工程扩展建议尚未实施。
- 研究图解与交互由本仓库制作；首页音频来自模型团队，界面动图来自 UI 原作者，均在线引用并注明出处，未下载远程媒体文件。
- 使用系统字体。音频 preload=none，点击才开始加载；动图按浏览器懒加载读取。播放器互斥，播放一首会暂停其他样例。无模型调用或数据上传。
- 浏览器验证范围和真实页面截图见 [QA.md](QA.md)。
