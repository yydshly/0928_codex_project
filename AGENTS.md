# Repository working notes

This repository is an ordered collection of research on external GitHub projects. The root README is the public summary and index; each `projects/NNN-name/` directory contains its own overview, research notes, images, and optional web demo.

- Assign project IDs in ascending three-digit order. Never renumber or reuse an assigned ID.
- Keep the root README index sorted by ID. Add a matching image-and-summary section for each real project.
- Record original repositories, the version studied, image provenance, and relevant licenses. Clearly distinguish original work from this repository's experiments.
- Do not invent project results, screenshots, or demo URLs. Add public links only after verifying them.
- Keep each project's web source and dependencies inside its own directory. Document the deployed subpath before publishing multiple demos.
